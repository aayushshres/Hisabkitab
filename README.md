# 📒 Hisabkitab

**Hisabkitab** is a simple and intuitive **Flutter expense tracker app** designed for **older Nepali users**. The UI is entirely in **Nepali language**, making it accessible and easy to use. Built with **Clean Architecture** and **BLoC** for state management, it requires **no login or signup** and stores all data **locally on the device**.

## 🚀 Features

- 🇳🇵 **Nepali language UI** for accessibility
- 📝 **Add expenses with a single click**
- 🗑️ **Swipe to delete** an expense
- 📅 Expenses sorted by **most recent**, divided by **week**
- 🗂️ **Categorize expenses** (e.g., food, transport, bills, etc.)
- 📊 **Expense graph** to visualize spending
- 📱 Data stored locally on device (no cloud / internet required)
- 🧩 **Clean Architecture** + **BLoC** state management

## 🛠️ Tech Stack

- **Flutter** – Cross-platform framework
- **BLoC** – State management
- **Clean Architecture** – Organized, scalable code structure
- **Local Storage** – Offline-first approach

## ▶️ Getting Started

### Prerequisites

- Flutter SDK → [Install Flutter](https://docs.flutter.dev/get-started/install)
- Android/iOS emulator or physical device

### Installation

```bash
# Clone the repository
git clone https://github.com/aayushshres/hisabkitab.git

# Navigate to project folder
cd hisabkitab

# Install dependencies
flutter pub get

# Run the app
flutter run
```
